About GuardianMart

Employee benefits portal — training instance.

What this is

GuardianMart is a fictional internal employee-benefits storefront, built as a hands-on training exercise for an internal Capture The Flag event. It is deliberately insecure. Every flaw in it was placed there on purpose, mapped to a category in the OWASP Top 10:2025.

All data in this application is synthetic. The employees, orders, addresses, phone numbers and support tickets are invented. No production data of any kind is present, and none should ever be added.

Rules of engagement

  • This instance runs on an isolated local network only.
  • Every challenge is solvable with a browser, DevTools and the URL bar. No extra tooling is needed.
  • Please do not attempt denial-of-service, or attack the host it runs on. Stay inside the application.
  • Nothing you learn here should be used against any system you are not authorised to test.
